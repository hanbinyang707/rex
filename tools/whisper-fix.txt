# 转写完之后的确定性替换。每行一条：错的→对的（全角箭头 →）。
# 这份是模板：拷到 ~/.config/rex/whisper-fix.txt 再改——那份优先，不进仓库。
#
# 为什么要这一层：whisper-prompt.txt 那份词表是**偏置**，不保证生效。
# 实测同一个词在两段录音里一次对一次错——33 秒那段「爽文」是对的，
# 换一段录音又变回「双文」。掰不回来的就放这里，这一层是确定的。
#
# ---- 中文没有词边界，这是无条件字符串替换，会误伤 ----
#
# 反面例子，**不要**加这种：
#   往文→网文     「通往文学」会变成「通网文学」
#   画线→划线     「画线条」会变成「划线条」
#
# 判断标准是「这个错法本身够不够独特」。下面每一条都想过一遍，
# 唯一有点风险的是 双文→爽文（会打到「双文明」），但那个词在自己的语料里
# 大概率不出现，而「爽文」是高频词，所以收着。拿不准就别放——让它错着、
# 改稿时顺手改，错一个字比静默改错一个字轻。
#
# 每次替换都打印「替换 N 处：X → Y」，不会静默改动。看到不对就来删那一行。
