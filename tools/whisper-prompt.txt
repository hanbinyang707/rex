# whisper 的初始提示词。转写前喂给模型，用来把同音词掰回来。

# ---- 实测（33 秒中文样本，large-v3-turbo）----
#
#   不给词表：  往文 / 赤心寻天 / 双文 / 新国变 / 哲理变
#   这份短词表：网文 ✓ 赤心巡天 ✓ 爽文 ✓ 新国辩 ✓ 哲理辩 ✓
#   更长的词表：网文 ✓ 但 赤心寻天 ✗ 双文 ✗ 新国变 ✗   ← 比短的还差
#
# 长的反而差，是因为 prompt 有长度上限（约 224 token，中文一个字就 1~2 token），
# 超了会被截断，等于把词表稀释掉。**所以这份文件要短。**
# 别往里堆分类词，只放**真的被听错过**的词。以 # 开头的行不算数。
#
# 另外试过 --carry-initial-prompt（每段都重喂词表），实测更差，所以没用。
#
# ---- 它做不到什么 ----
#
# 这是偏置不是规则。同一次测试里「我自己划的线」仍然被写成「画的线」，
# 加了词也没掰回来。转写稿要自己过一遍，别当成定稿。
#
# 加词：把这个文件拷到 ~/.config/rex/whisper-prompt.txt 再改——那份优先，不进仓库，git pull 也冲不掉。
# 下次 rex text 自动生效，不用重编任何东西。

#   诡秘之主、奇葩说。
