# whisper 的词表。转写时中文段的每个 30 秒窗口都喂给模型，用来把同音词掰回来。
#
# 这份模板一个词都没有：每个人被听错的词不一样，自己加。没有词时 whisper 什么提示都不收。
# 加词：把这个文件拷到 ~/.config/rex/whisper-prompt.txt 再改——那份优先，不进仓库，git pull 也冲不掉。
# 下次 rex text 自动生效，不用重编任何东西。以 # 开头的行不算数。
#
# ---- 怎么写 ----
#
# **只列词，顿号或空格隔开，可以换行接着写。不要写成句子，不要句号和逗号。**比如：
#
#   网文、爽文、即兴、neo-soul、
#   诡秘之主、奇葩说
#
# 词表每个窗口都在，whisper 会照着它的样子写。同样 20 个词、同一段 150 秒的讲课：
#
#   a、b、c                          34 条字幕，一条中位 2 秒
#   a、b、c。                         5 条，一条 30 秒      ← 只差一个句号
#   a, b, c                           5 条，一条 30 秒
#   以下是普通话讲课。常见词：a、b、c    5 条，一条 30 秒
#
# 认词的效果差不多，但一条字幕 30 秒的话，字幕、录音台搜索、校对定位都只能准到 30 秒。
# 想要带标点的整段稿子才写成句子。词表里有句号或逗号时，转写开头会说一声。
#
# 只放**真的被听错过**的词，别往里堆分类词。上限 223 token（中文一个字 1~2 个），超了开头会被
# 截掉。转写开头会打印「词表 N token（上限 223）」。更早在一段 33 秒的样本上测过（2026-08）：
#
#   不给词表：  往文 / 赤心寻天 / 双文 / 新国变 / 哲理变
#   短词表：    网文 ✓ 赤心巡天 ✓ 爽文 ✓ 新国辩 ✓ 哲理辩 ✓
#   更长的词表：网文 ✓ 但 赤心寻天 ✗ 双文 ✗ 新国变 ✗   ← 比短的还差
#
# ---- 它做不到什么 ----
#
# 这是偏置不是规则，会纠对也会带偏。转写稿要自己过一遍，别当成定稿。
#
#   · 掰不回来：33 秒那次「我自己划的线」仍然被写成「画的线」，加了词也没用
#   · 带偏相近的词：列了「爱斯梅拉达」「君士坦丁堡」之后，本来对的「埃及金字塔」变成了
#     「爱斯梅基 金士坦」。看到这种情况，把被带偏的词（埃及 金字塔）也加进来，实测就回来了
#   · 听不清的地方可能填进表里的词：一段讨论数据的录音里冒出一次「赤心巡天」
#
# ---- 2026-08 到 2026-11，这份词表在转写时其实没生效 ----
#

# --carry-initial-prompt -mc 词表长度+1——每个窗口都带词表，前文照样一个 token 都不回灌。来龙去脉
# 见 whisper_run.py 文件头。那时还试过 --carry-initial-prompt，记的是「实测更差」，不过那时
